Formules ML

MSE = (1/n) Σ (y − ŷ)²  ·  MAE = (1/n) Σ |y − ŷ|
R² = 1 − Σ(y − ŷ)² / Σ(y − ȳ)²
Cross-entropy = −Σ yj log ŷj  ·  BCE = −[y log ŷ + (1−y) log(1−ŷ)]
Précision = VP/(VP+FP)  ·  Rappel = VP/(VP+FN)
Accuracy = (VP+VN)/total  ·  F1 = 2PR/(P+R)
Standardisation : x′ = (x − μ)/σ  ·  Min-max : x′ = (x − min)/(max − min)
Couche dense : y = σ(Wx + b), n·p + n paramètres
Gradient : θ ← θ − η ∇L(θ)  ·  Recuit : P = e−Δf/T
Bayes : P(c|x) = P(x|c)·P(c) / P(x)  ·  Pseudo-inverse : θ = X⁺Y
Régression 1D :
a = (N Σxy − Σx Σy) / (N Σx² − (Σx)²)
b = (Σx² Σy − Σx Σxy) / (N Σx² − (Σx)²)

Les pièges qui coûtent des points

  • BJ ne saute que sur échec immédiat, GBJ se fie au graphe, CBJ mémorise les conflits rencontrés et les propage.
  • FC filtre les voisines de la variable courante ; MAC rend arc-consistantes toutes les non instanciées.
  • Une méthode incomplète ne prouve jamais qu'il n'y a pas de solution.
  • Arc-consistance : ne pas oublier dx ≠ ∅ dans la définition.
  • L'ordre des valeurs ne change rien sur un problème inconsistant ; celui des variables, si.
  • Activation identity = modèle linéaire, même avec dix couches.
  • Accuracy trompeuse si les classes sont déséquilibrées → précision, rappel, F1.
  • Validation pour régler les hyperparamètres, test pour la note finale, jamais l'inverse.
  • MSE tire vers la moyenne, MAE vers la médiane.
  • Prolog : = unifie, == compare, =:= calcule. 5 = 3+2 est faux.
  • Conséquence logique : on ajoute la négation de ce qu'on veut prouver, et on cherche □.
